# Cuttlefish v0.23.7

## Trust boundaries, runtime integrity, and Windows readiness

Cuttlefish v0.23.7 is a security and reliability maintenance release. It
closes the trust-boundary defects found in the latest comprehensive audit,
keeps agent execution away from control-plane state, repairs scheduling and
lifecycle races, and makes several destructive operations atomic. It also
rolls up the Windows 11 x64 runtime work, orchestration repairs, accessibility
improvements, dependency refreshes, and performance work accumulated since
v0.23.6.

### Highlights

- Authentication is required by default, including on loopback. A dashboard
  opened by `cuttlefish start` exchanges a short-lived, single-use launch
  capability for a revocable operator session; a process merely running on the
  same machine is no longer treated as the operator.
- Delegated approval authority is administrator-only. Scoped agents cannot
  select arbitrary control-plane directories or substitute a more permissive
  engine, and implicit/fallback/retry sessions use server-owned workspaces
  outside the Cuttlefish home.
- Email auto-ingest accepts only a trusted receiver's aligned DMARC pass and
  fails closed on missing, forged, duplicate, or ambiguous authentication
  results. External prompt envelopes now resist reserved-marker injection.
- Gateway startup, custom ports, listener detection, session fairness,
  orchestration holds, Claude PTY ownership, and cron timeout settlement have
  all been repaired and regression-tested.
- Session/employee deletion is coordinated across boards, queues, engines,
  registry records, and org state. Protected failures restore snapshots and do
  not perform irreversible cleanup.
- CLI behavior is consistent for bare help, JSON failures, empty skill
  searches, source setup, and current Codex argument parsing.
- Rapid Send double-click no longer interrupts a new message. Whisper download
  focus behavior and dual-lane confirmation now meet their intended modal and
  explicit-choice contracts.
- Windows installations now resolve npm/pnpm engine shims, terminate process
  trees, understand Windows paths, run the development workflow, invoke npx
  safely, and locate the Kokoro Python environment. Windows CI protects the
  release archive path.

### Operator notes

- A manually opened dashboard must be paired; use the browser opened by
  `cuttlefish start` for the automatic local flow. Set `gateway.authDisabled`
  only when unauthenticated access is explicitly intended.
- Email inboxes using `autoIngest` must configure the receiving MTA's exact
  `trustedAuthservIds`. The border MTA must strip untrusted inbound
  `Authentication-Results` headers and stamp its own aligned DMARC result.
- Cuttlefish continues to require Node.js 24.

## Publication status

The GitHub release was published on 2026-08-12, but npm rejected publication
after the validation and provenance steps. The release consequently has no
platform assets, and npm/Homebrew remain at `0.23.6`. The command below is the
post-recovery verification target; it does not work until publication is
successfully recovered or superseded.

After successful recovery:

```bash
npm install -g cuttlefish-cli@0.23.7
cuttlefish --version
```

Expected output: `0.23.7`.
