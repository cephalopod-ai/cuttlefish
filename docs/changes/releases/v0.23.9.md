# Cuttlefish v0.23.9

## Summary

Cuttlefish v0.23.9 is the immutable recovery release for the incomplete
v0.23.7 publication and unpublished v0.23.8 candidate. It ships the accumulated
A2A federation, Vibe, security, recovery, and architecture work, then refreshes
the CLI/model registry against current provider discovery surfaces.

## Highlights

- Adds opt-in A2A Protocol 1.0 HTTP+JSON federation with authenticated,
  service-allowlisted inbound and outbound routing; durable restart recovery;
  bounded task projection; preserved operator approvals; and hardened
  SSRF, redirect, DNS, origin, credential, and artifact boundaries.
- Adds Mistral Vibe as a first-class ACP engine and retains the focused gateway
  service and configuration-schema boundaries introduced by the v0.23.8
  candidate.
- Updates fresh defaults and documented catalogs for Claude Fable 5.1, Gemini
  3.8 Flash Medium, Grok 4.6/4.5, and exact-tag Ollama completion models.
- Queries Codex, Antigravity, Grok, and Ollama through bounded live discovery;
  successful Codex/Grok discovery is authoritative, so removed provider models
  cannot return through stale configuration.
- Probes all 11 registered engine adapters during setup while keeping optional,
  uninstalled CLIs hidden.

## User-visible changes

- New setups select `claude-fable-5-1`, `gemini-3.8-flash-medium`, `grok-4.6`,
  and `gemma4:26b` where those engines apply.
- Antigravity model IDs now match the canonical tabular output of `agy models`.
- Ollama model selection preserves exact tags, records discovered context
  length, and excludes embedding-only models from completion choices.
- The dashboard, setup flow, limits command, gateway refresh route, session
  defaults, escalation metadata, and security-review defaults share the same
  refreshed model information.
- A2A federation remains disabled until explicitly configured. Inbound clients
  and outbound peers require service allowlists, and external peers cannot
  approve privileged Cuttlefish actions.

## Documentation

- README, installation, release, user-manual, feature-inventory, documentation
  inventory, and test-ledger surfaces now describe the current recovery release
  and provider-driven model behavior.
- The v0.23.8 statement is retained as unpublished candidate history rather than
  presented as an installable release.

## Validation

- `pnpm typecheck`
- `pnpm lint`
- `pnpm test` — 334 backend files, 2,774 passing tests, 3 intentional skips in
  the CLI compatibility validation run; workspace contract and web suites also
  passed through the root task.
- `pnpm build`
- `pnpm --filter cuttlefish-cli verify:package`
- Provider-native version/model probes for the installed Claude, Codex,
  Antigravity, Grok, Ollama, and Vibe CLIs; a real local Ollama adapter smoke
  returned the expected sentinel.
- Full-history and tracked-tree secret scanning found no repository leak.

The GitHub release workflow repeats typecheck, test, lint, build, the exact
tag/package-version check, and package-content verification before npm publish.

## Compatibility and breaking changes

No breaking CLI, configuration, API, or persisted-data change was identified.
Node.js `>=24 <25` remains required. Existing engine configuration remains
valid; when a supported CLI provides a live catalog, that catalog now owns
availability and stale omitted model IDs are removed from the active registry.

## Known issues

- Optional engine CLIs are not bundled. Pi, Kiro, Hermes, Kilo, and Aider were
  absent from the local runtime matrix and were not live-smoked; provider
  authentication is still required before any installed engine can run.
- Codex CLI 0.153.1 continued to advertise GPT-5.4 during release validation,
  so Cuttlefish retains it while the provider lists it and will drop it when
  successful live discovery omits it.
- Dependency scanners report open high-severity transitive advisories for
  `browserslist` in the lockfile and `deepmerge-ts` through
  `mailparser > html-to-text`; no critical advisory was reported, and
  Dependabot could not resolve the current Browserslist advisory to an
  installable patched version.
- No paid live Claude, Codex, Antigravity, Grok, or Vibe generation turn was
  performed as part of the compatibility matrix.
